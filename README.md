## Best Version Control Practices
For each team member there should be a branch - Ketas, Sabo, Empey. While working on lab code individually all members should have their own branches checked out. It is generally best practice to only have the master branch pulled if ALL team members agree upon this. Once lab code is working on a particular branch, that code should be merged into the master branch. Whichever team member is going to merge their branch should set the other two members as reporters to review the code before it goes into the master branch. Team members should also send a text once they have created their pull/merge request so that all members are aware.

## How to Create a New Branch:
1. First pull the origin: git pull origin
2. Checkout a new branch: git checkout -b (name of branch)
3. Check that working directory is new branch: git branch
4. Check that working tree is clear: git status
5. Begin to make changes and use push/pull as needed
